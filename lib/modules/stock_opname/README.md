# Stock Opname

Fitur frontend: buat draft opname per gudang, input stok fisik per produk, lihat selisih terhadap stok sistem, detail, terapkan hasil, batalkan, dan hapus draft. Penyelesaian opname memperbarui stok global ProductModel ke nilai fisik.

Catatan: ProductModel saat ini memiliki stok global, bukan stok per gudang. Perlu saldo per gudang untuk opname yang benar-benar terisolasi per lokasi.
