# Modul Produk & Kategori

## Fitur
- Daftar produk dummy dengan SKU, barcode, kategori, satuan, stok, minimum stok, dan lokasi.
- Pencarian berdasarkan nama, SKU, atau barcode.
- Filter produk berdasarkan kategori.
- Indikator stok rendah.
- Tambah dan edit produk melalui form.
- Tambah, ubah nama, dan hapus kategori.
- Kategori yang masih digunakan produk tidak dapat dihapus.
- Saat kategori diganti nama, produk terkait ikut diperbarui.

## Catatan
Data masih disimpan di memory melalui GetX RxList. Data akan kembali ke dummy awal ketika aplikasi dimulai ulang. Integrasi API, database, barcode scanner SUNMI, dan validasi SKU/barcode unik akan dibuat pada tahap berikutnya.
