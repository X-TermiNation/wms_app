# Transfer Barang

Fitur frontend: daftar dan pencarian transfer, filter status, buat draft dengan gudang asal/tujuan dan beberapa item, detail, tandai selesai, batalkan, dan hapus draft.

Catatan data: model produk saat ini hanya menyimpan total stok global, bukan saldo per gudang. Karena itu transaksi transfer tidak mengubah total stok global; saldo per gudang perlu dimodelkan sebelum integrasi backend/scanner produksi.
